# 活动提示词与可复现性

`VERSION` 是活动提示词的唯一版本来源。当前活动链路为系统提示词、事件整理提示词、运行时中性追问模板和 `event-v0.3` Schema。`backend.adapter.build_prompt()` 生成完整模型输入的系统部分；成功和失败审计均记录 `prompt_version`、`prompt_sha256`、`input_sha256` 和 `model_id`。修改任意活动文字、模板或 Schema 都会改变提示词哈希；行为变化还应递增 `VERSION`。

03、04 是未接入模型的历史参考，不属于活动提示词，也不进入活动哈希。

当前安全约束采用保守抽取。摘要必须复制完整当前原文，claims 必须按记录 ID 绑定其完整原文和来源，claim.text 与非空 quote 一致。外围空白可去除，任何片段截取均拒绝。对抗测试证明连续子串仍会截断剂量、丢失条件或跨句否定，所以原先的连续片段方案已收紧，分句提取留待后续验证。追问仅允许已审阅的中性模板。自由改写、无法证明的事实和无引用 claim 会被拒绝，原文仍保留。规则只能降低可检测的错误，不能证明语义完整、医学正确或临床安全。

来源标签沿用后端记录元数据。即使是 `clinician_evidence`，也只是输入标签，当前系统没有验证上传者医生身份或文档真实性的能力；不得把该标签展示为医生已审核当前 AI 草稿。
