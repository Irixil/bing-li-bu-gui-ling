## 运行边界

本项目服务只监听本机 127.0.0.1，默认一个本地数据库。旧兼容账号路径仍在，不能直接当公网多人系统。危险规则是关键词兜底，否定、历史、隐喻可能误报，未覆盖表达可能漏报；它不诊断、不改药。

## 发布前自查结论

这是开发仓库分享，不是公网医疗服务上线。

- 核心后端路径与重要失败路径：在上述本机/Mock 范围内通过。明天整个网页 demo：尚未验证，需前端完成后排练。
- 改动代码：原文落库先于模型调用，模型异常捕获不包住数据库提交，失败写审计，旧原文和危险历史不被覆盖。保留来源、时间及安全校验；备份使用 SQLite backup API。
- 依赖版本固定；仅使用 Python 标准库和 jsonschema 运行后端。测试依赖单独列出。未执行第三方漏洞数据库扫描，不能据此声称没有已知漏洞。
- 没有将旧 `.env`、运行数据库、依赖目录或旧前端复制到本仓库。提交前将检查实际 Git 暂存清单。
- 原始测试凭据是单测里公开的虚构字符串，不是用户真实凭据。自动化/AI 自查不代替独立临床或安全审查。
