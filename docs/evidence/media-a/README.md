- 数据库和媒体原件的联合备份/空目录恢复已通过本地测试；严格原子快照仍不是当前承诺。
- 真实 ASR/OCR、真实浏览器、真实录音暂停续录或生产资源边界。

## 实现后需要提交的可复现证据

每项证据注明日期、Git 提交、Python/浏览器环境、命令或操作、预期、实际结果和是否 Mock。只使用合成或明确授权的脱敏媒体。

1. 系统能力：公开的总字节、单片字节、片段数和支持 MIME；未配置时写入口关闭。
2. 上传：首次、同键同内容重放、同键变内容 409、缺片、损坏、写盘失败和数据库失败。
3. 合并：目标浏览器生成的多个暂停片段按序合并，前后内容可播放且可识别。
4. 查询读取：失败/未关联项刷新可找回；路径穿越、符号链接、文件替换和 token URL 被阻断。
5. 识别：202、轮询成功、显式 Mock、未配置、超时、网络、鉴权、限流、空文字和非法响应。
6. 并发恢复：重复/并发识别只占用一次；处理中重启转 interrupted；迟到结果不覆盖新尝试或人工修订。
7. Event：先保存全文和危险结果，再唯一关联；关联失败不重新识别；超过 10000 字符不截断。
8. 交接：没有 Event 的失败媒体仍作为无医学摘要的附件可见；旧快照不可变。
9. 备份恢复：空目录恢复数据库、原件、哈希、初稿、危险状态、关联和旧文本记录；缺失/损坏被发现。
10. 全量回归：pytest、TypeScript 合同、Mock 评估、演示流程及目标浏览器验收。

## 禁止进入本目录的内容

- `.env`、API key、token、Authorization header 或供应商原始错误正文。
- 未经授权的录音、照片、身份证明、真实病历或运行数据库。
- 仅写“HTTP 200”的截图、无法复现的手工结论或把 Mock 标成真实成功的材料。

真实能力没有证据时统一写“未验证”，失败项保留可见，不通过删验收项来声明完成。
