# 病历不归零·内测版实施方案（最小闭环修订）

> 依据 `spec-minimal-loop-v4.md`，取代 `plan-device-binding-v3.md`。

## 1. 前端

1. 删除设备绑定令牌消费、会话检查、状态事件和设置页绑定卡片。
2. 删除文字整理、录音识别和照片识别前的 `confirm` 对话框。
3. 保存录音或照片原件后立即发起识别；识别成功后自动建立本地记录关联。
4. 识别失败统一显示原件已保存和可执行的重试提示，不出现家属、绑定或开通文案。
5. 设置页仅保留本地加密备份、当前设备和内测反馈；暂隐藏云备份操作。

## 2. 后端

1. `local_first` 模式的 AI 整理、录音识别和照片识别不再要求应用会话、设备会话或 CSRF 令牌。
2. 这些请求仍必须通过精确 `ALLOWED_ORIGIN` 检查，并继续执行内容长度、类型、文件大小和响应结构校验。
3. 删除文字 AI 请求中的 `consent=true` 强制字段。
4. 旧管理员登录和设备激活代码可暂作兼容保留，但新前端不得调用，也不得成为最小闭环的运行条件。
5. 云备份不纳入本轮闭环验收，不改动已存在的后端备份保护代码。

## 3. 验证

1. 前端合同测试确认没有设备激活调用、家属绑定错误或 AI 发送确认对话框。
2. HTTP 回归确认允许的前端来源无会话即可调用文字和媒体 AI，未信任来源仍被拒绝。
3. 前端测试覆盖媒体保存后自动识别、自动建立记录和失败可重试。
4. 全量 Python、Node 和 TypeScript 检查通过。
5. 在隔离浏览器和 Mock AI 下走完：建立本机加密仓库 → 保存资料 → 无弹窗自动识别 → 读取记录 → 生成就诊交接材料。
