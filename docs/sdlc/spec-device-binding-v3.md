# 病历不归零·内测版产品规格（设备绑定修订）

> 继承并修订 `spec-split-web-api-v2.md`。决策来源：2026-09-17 项目所有者确认“老人只解锁一次本机资料，不再输入第二个网站密码；在线能力由家属/管理员绑定设备，绑定失效也不能阻断本地记录”。未被本文件修改的 v2 条款继续有效。

## 1. 访问模型

- 老人端只要求本机恢复口令，用于解锁当前浏览器中的加密健康资料；页面不显示网站访问密码框。
- 家属或管理员使用短时设备绑定链接在该设备打开一次，后端随后通过持久、HttpOnly 的设备会话保护在线 AI 和云备份。
- 设备尚未绑定或绑定失效时，本地记录、查找、修订和本地备份继续可用；页面只提示联系家属重新绑定，不要求老人处理管理员密码。
- 设备绑定只授予在线能力访问资格，不代替每次 AI 外发前的明确同意。
- 后端继续校验精确前端来源、设备会话、CSRF、内容大小和操作权限。

## 2. 修订后的必须结果

- [DZ-MUST:R1] 使用者能在手机和电脑的受支持浏览器中打开“病历不归零·内测版”；老人只需输入本机恢复口令，不需再输入网站访问密码；未由家属或管理员绑定的设备不能使用在线 AI 或备份能力，未解锁本地数据的人不能读取或修改当前设备上的健康资料。
- [DZ-MUST:R9] 页面在设备绑定失效时明确提示联系家属且不阻断本地功能，不将旧会话或失败请求显示成本次成功。

## 3. 设备绑定验收

1. 前端从 `5173` 能通过短时绑定链接建立有明确有效期的持久设备会话，地址中的绑定片段会立即清除。
2. 老人端源码和页面都没有网站密码输入框，也不调用管理员密码登录接口。
3. 未配置的第三方网页不能激活设备或携带会话调用后端；合法前端跨域请求包含准确的允许来源和凭证头。
4. 绑定失效后，本地新增、查找、修订和本地备份仍可完成；在线操作给出家属可执行的重新绑定说明。
5. 本地开发可显式启用只允许回环来源和回环客户端的自动绑定；生产环境默认关闭。
